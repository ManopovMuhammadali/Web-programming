CSS Grid & Flexbox.

Practical exercises covering modern CSS layouts, responsive design and reusable custom properties.

01 — Flexbox Layout

Flexbox arranges elements in a row or column. It helps control alignment, spacing and wrapping.

Item 1
Item 2
Item 3

CSS Code

.container {
  display: flex;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

.item {
  flex: 1 1 120px;
}
Result: The items are displayed in a flexible row and wrap when space becomes limited.

02 — CSS Grid Layout

CSS Grid creates two-dimensional layouts using rows and columns.

03 — Responsive Layout

Responsive Grid automatically adjusts the number of columns according to available screen width.

CSS Code

.container {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(150px, 1fr));
  gap: 12px;
}
Result: The cards automatically rearrange when the browser window becomes smaller. Try resizing the browser to test it.

04 — CSS Custom Properties

Custom properties allow reusable values to be stored and accessed using the var() function.

Reusable CSS variables

This example uses variables for background, text color, accent color and border radius.

CSS Code

:root {
  --background: #24434a;
  --text: #ffffff;
  --accent: #f1d2a6;
  --radius: 10px;
}

.card {
  background: var(--background);
  color: var(--text);
  border-radius: var(--radius);
}
Result: Reusable variables make styles easier to maintain and update.

05 — Layout Reflection

What is the difference between Flexbox and Grid?

Flexbox is mainly used for one-dimensional layouts, arranging elements in a row or column. Grid is used for two-dimensional layouts with rows and columns.

When should each be used?

Flexbox is useful for navigation bars, buttons and aligning content. Grid is useful for galleries, card collections and complete page layouts.

Why are custom properties useful?

They allow common CSS values to be reused throughout a website, making styles easier to maintain.

Conclusion

Flexbox, Grid and CSS custom properties are important tools for building organized and responsive websites. Choosing the correct layout method improves the experience on desktop and mobile devices.
