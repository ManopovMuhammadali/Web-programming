WEEK 10 / PERFORMANCE PROJECT

Website Optimization

This project demonstrates techniques that improve website loading speed, image delivery, and responsive design.

01 — Image Optimization

Images should be compressed and delivered in modern formats such as WebP or AVIF to reduce file size.

Example: Responsive image with lazy loading.

02 — Responsive Images

The browser can choose an image size based on the screen width.

<img
src="small-image.webp"
srcset="small-image.webp 480w, large-image.webp 1000w"
sizes="(max-width: 600px) 100vw, 700px"
alt="Example image"
loading="lazy">

03 — Loading Performance

Lazy loading prevents off-screen images from downloading before they are needed.

<img src="photo.webp" alt="Description" loading="lazy">

JavaScript files can use defer so the browser can parse the HTML without waiting for the script to execute.

<script src="app.js" defer></script>
