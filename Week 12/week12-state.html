Practice checklist

  • State belongs to a component and triggers a re-render when updated.
  • Use functional updates when the new value uses the previous value.
  • Replace objects and arrays instead of mutating them.
  • Calculate values such as totals from current state during render.
  • Lift state to a shared parent when multiple children need to read or update it.
