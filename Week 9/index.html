Week 9 GitHub Homework

Repository creation and deployment tasks

Monday — Git and GitHub

  1. Create a public GitHub repository named webpro-w9.
  2. Initialize a local Git repository.
  3. Create an index.html containing your name and date.
  4. Commit your changes and push them to GitHub.
  5. Enable GitHub Pages using the main branch and root folder.
  6. Submit the repository URL and live website URL on the LMS.

Friday — Deploy the Book Search App

  1. Use the Book Search App developed in Weeks 6–7.
  2. Check that its search functionality works.
  3. Fix incorrect file paths and remove debugging messages.
  4. Create a public repository named webpro-book-search.
  5. Push the app files and enable GitHub Pages.
  6. Test the deployed website and submit its live URL.
