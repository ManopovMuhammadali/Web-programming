What I practiced

Concepts from the lecture notes and study guide

  • Distinguish component state from read-only props.
  • Use useState to remember values and trigger re-renders.
  • Update objects and arrays immutably, using functional updates when the next value depends on the previous one.
  • Share state between related components by lifting it to their common parent.
  • Use useEffect with intentional dependencies to synchronize with external systems.
  • Handle loading and error states, abort stale requests, and clean up timers and subscriptions.
