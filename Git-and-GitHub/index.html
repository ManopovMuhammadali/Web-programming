02 — Git Basic Commands

Check the current repository status:

git status

Stage a changed file:

git add index.html

Create a commit:

git commit -m "Update portfolio homepage"

Upload your changes to GitHub:

git push origin main
Important: These commands assume you are already inside the cloned repository and that your main branch is connected to the origin remote.

03 — Creating and Managing Branches

A branch allows you to work on new features without changing the main branch immediately.

Create a new branch:

git switch -c feature/portfolio-update

Stage and commit your changes:

git add index.html
git commit -m "Improve portfolio layout"

Push your branch:

git push -u origin feature/portfolio-update

Then open GitHub, create a Pull Request from your feature branch into main, review the changes, and merge it.

Update your local main branch after merging:

git switch main
git pull origin main

04 — GitHub Pages Deployment

GitHub Pages publishes static websites directly from a GitHub repository.

  1. Open the repository on GitHub.
  2. Open Settings.
  3. Select Pages.
  4. Choose Deploy from a branch.
  5. Select main as the branch.
  6. Select the root folder (/).
  7. Save your configuration.
  8. Visit the published HTTPS address.

My portfolio is already published using GitHub Pages. This section documents the deployment process.

05 — Custom 404 Error Page

A 404 error appears when a visitor requests a page that does not exist.

A custom 404 page can guide visitors back to the homepage instead of displaying an unhelpful generic error.

06 — Practical Checklist

  • Understand repository initialization and status.
  • Stage and commit changes.
  • Push changes to a remote repository.
  • Create and switch branches.
  • Understand pull requests and merging.
  • Publish a website with GitHub Pages.
  • Create and test a custom 404 page.

This is a learning checklist, not proof that every exercise has already been completed. Complete and verify the branch and pull-request exercises in GitHub.
