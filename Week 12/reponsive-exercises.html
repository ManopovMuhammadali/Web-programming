01 — Mobile-First Design

Mobile-first design means creating the basic layout for small screens first, then adding more complex layouts as the available screen width increases.

CSS Code

/* Default: mobile layout */

.container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet */

@media (min-width: 620px) {
  .container {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

/* Desktop */

@media (min-width: 960px) {
  .container {
    grid-template-columns: repeat(3, minmax(0, 1fr));
  }
}
Result:

The content begins in one column and expands into two or three columns as the screen becomes wider.

02 — CSS Media Queries

Media queries allow CSS rules to apply only when certain conditions are met, such as a minimum or maximum viewport width.

CSS Code

/* Base navigation */

.navigation {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

/* Smaller screens */

@media (max-width: 600px) {
  .navigation {
    flex-direction: column;
    align-items: flex-start;
  }
}

/* Larger screens */

@media (min-width: 900px) {
  .navigation {
    flex-direction: row;
    align-items: center;
  }
}
Result:

Navigation items can change their direction according to the available screen width.

03 — Fluid Typography with clamp()

The CSS clamp() function creates a flexible value with a minimum, preferred and maximum size.

CSS Code

.heading {
  font-size: clamp(
    2rem,
    5vw,
    4.5rem
  );
}

.container {
  width: min(100% - 2rem, 72rem);
  margin-inline: auto;
}
Result:

The heading scales with the viewport but never becomes smaller or larger than its limits.

04 — Responsive Grid and Flexbox

CSS Grid and Flexbox help create layouts that can adjust when the browser size changes. The auto-fit and minmax functions are useful for flexible card collections.

CSS Grid Code

.card-grid {
  display: grid;

  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));

  gap: 16px;
}

Flexbox Code

.flex-container {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
}

.flex-item {
  flex: 1 1 220px;
}
Result:

Grid automatically adjusts the number of columns. Flexbox lets items wrap into additional rows.

05 — Responsive Images and Containers

Images and visual elements should not force a page to become wider than the screen. A maximum width of 100% allows images to fit their parent containers.

CSS Code

img {
  display: block;
  max-width: 100%;
  height: auto;
}

.container {
  width: min(100% - 2rem, 72rem);
  margin-inline: auto;
}
Result:

Visual elements preserve their proportions and stay within the available content width.

06 — Responsive Design Reflection

What is responsive web design?

Responsive web design is an approach to web development in which a website adapts to different screen sizes, resolutions and devices.

Why is mobile-first development useful?

It ensures that important content and functionality work on smaller screens before additional desktop features and layouts are introduced.

What is a media query?

A media query is a CSS feature that applies styles based on conditions such as screen width or user accessibility preferences.

What does clamp() do?

It limits a CSS value between a minimum and maximum size while allowing a preferred fluid value between those limits.

Conclusion

Responsive design improves the usability of websites on mobile devices, tablets and desktop computers. Mobile-first CSS, flexible layouts, media queries and fluid typography help create interfaces that remain readable and functional across screen sizes.
