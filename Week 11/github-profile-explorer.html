01 — Fetch API and JSON


  

    The application sends a GET request to GitHub's public
    API. The response is converted into a JavaScript object
    using the json() method.
  


  
async function getProfile(username) {

  const response = await fetch(
    `https://api.github.com/users/${username}`
  );

  if (!response.ok) {
    throw new Error("Unable to retrieve profile.");
  }

  const data = await response.json();

  console.log(data.name);
  console.log(data.public_repos);

  return data;
}


  

    This project uses async/await because API requests are
    asynchronous. The browser can continue responding
    while it waits for the server.
  








  
02 — Rate limits and error handling


  

    Public, unauthenticated GitHub REST API requests are
    limited to 60 requests per hour per originating IP address.
    The application reads the response headers to display
    the current allowance.
  


  
Important response headers


  
    
    
  • X-RateLimit-Limit — maximum requests.
    • 
    
  • X-RateLimit-Remaining — requests remaining.
    • 
    
  • X-RateLimit-Reset — reset time as a UTC timestamp.
    • 
    
  • Retry-After — how long to wait when provided.
    • 
  


  
Error cases


  
    
    
  • 404 — the requested user does not exist.
    • 
    
  • 403 — forbidden or a rate-limit restriction.
    • 
    
  • 429 — too many requests.
    • 
    
  • 5xx — a server-side problem.
    • 
    
  • Network error — the API cannot be reached.
    • 
    
  • Timeout — the request took too long.
    • 
  


  

    The application does not automatically repeat a
    rate-limited request. This prevents additional requests
    from making the restriction worse.
  








  
03 — Project reflection


  


    
What is an API?

    

      An API allows different software systems to communicate.
      It provides a structured way for an application to
      request information or services from another system.
    


    
What is JSON?

    

      JSON is a lightweight data format that represents
      information using objects, arrays and values.
      JavaScript can convert JSON into objects for processing.
    


    
Why is error handling important?

    

      An API might be unavailable, a user may not exist,
      or the application may reach its request limit.
      Clear error messages help users understand what happened.
    


    
What did I learn?

    

      I learned how to retrieve external data, process JSON,
      display dynamic information and handle HTTP errors
      when building an API-powered web application.
