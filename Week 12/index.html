Learning outcomes

  • Use useState to preserve values between renders.
  • Update objects and arrays immutably, using functional updates when state depends on its previous value.
  • Lift shared state to the closest common parent and calculate derived values during render.
  • Use effects with accurate dependencies to synchronize with external data or timers.
  • Show loading and error states, cancel outdated requests, and clean up timers.
