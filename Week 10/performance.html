WEEK 10 / PERFORMANCE PROJECT

Website Optimization and Performance Report

This project demonstrates image optimization, responsive images, efficient loading, and performance testing.

01 — Image Optimization

Images should be compressed and delivered in modern formats such as WebP or AVIF to reduce file size.

Example: Lazy-loaded image.

02 — Responsive Images


<img src="small.webp"
srcset="small.webp 480w, large.webp 1000w"
sizes="(max-width: 600px) 100vw, 700px"
width="700" height="467"
alt="Description"
loading="lazy">

03 — Efficient Script Loading

The defer attribute allows HTML parsing to continue without waiting for the script to execute. 


<script src="app.js" defer></script>
