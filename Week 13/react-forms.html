Let React control form values.

Each controlled value follows one loop: the user types, onChange updates state, and React renders the current state back into the field.

Practice checklist

  • Controlled fields always receive a string value and update it in onChange.
  • A shared handler uses each field's name to update the right state property.
  • Forms call preventDefault() before handling data in the page.
  • Validation errors are connected to fields and announced clearly.
  • A ref is reserved for the uncontrolled example; normal form values stay in state.

All form data is sample input held in component state. Nothing is sent or saved.
