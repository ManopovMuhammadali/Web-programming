WEEK 09 / PERFORMANCE LAB

Web performance exercises.

Practice modern image formats, lazy loading, script optimization and Lighthouse testing.

01 — Modern Image Formats

WebP and AVIF can reduce image size. The picture element allows the browser to choose a supported format with a fallback. 

<picture>
  <source
    srcset="image.avif"
    type="image/avif">

  <source
    srcset="image.webp"
    type="image/webp">

  <img
    src="image.jpg"
    alt="Description of the image"
    width="800"
    height="500">
</picture>

02 — Lazy Loading

Lazy loading delays downloading images that are not initially visible. 

<img
  src="gallery.webp"
  alt="Gallery photograph"
  width="700"
  height="450"
  loading="lazy"
  decoding="async">

Do not lazy-load the main hero image if it is the Largest Contentful Paint element.

03 — Deferred JavaScript

The defer attribute allows the browser to parse HTML while downloading an external script. 

<script src="app.js" defer></script>

Deferred scripts execute after HTML parsing, in document order.

04 — Lighthouse Performance Test

  1. Open your portfolio in Google Chrome.
  2. Open Developer Tools.
  3. Select Lighthouse.
  4. Choose Mobile and Performance.
  5. Run the audit and save the report.
  6. Apply your selected optimizations.
  7. Publish the updated site.
  8. Run the audit again under the same conditions.
  9. Compare both reports.

Record actual results for Performance, LCP, INP and CLS. Lighthouse lab testing may report Total Blocking Time instead of field INP.
